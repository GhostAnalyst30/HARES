# Assets 3D (opcionales)

Coloca aquí modelos GLB para sustituir los procedurales:

| Archivo | Agente |
|---------|--------|
| `human.glb` | Persona |
| `ugv.glb` | Rover Madre |
| `uav.glb` | Dron |

Escala recomendada en metros reales. Si el archivo no existe, el twin usa mallas procedurales detalladas (`shared/agents/models.js`).

Herramientas: Blender → Export glTF Binary (.glb).
